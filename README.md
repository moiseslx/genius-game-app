# Genius

Genius é um aplicativo Android de quiz de multiplicação desenvolvido nativamente em Java. O app oferece três modos de jogo: Prática (desafios cronometrados), Didático (estudo das tabuadas) e Multijogador (confronto online). Conta com autenticação de usuários, placar de líderes e estatísticas de desempenho, utilizando Firebase Authentication, Firebase Realtime Database e Firebase Storage como backend. A interface foi construída com AndroidX, Material Design e Navigation Component.
